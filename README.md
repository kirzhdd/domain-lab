# domain-lab
my study windows domain + trust

## theory
что нужно для подготовки сервера перед развертыванием домена и как это сделать на
виндовс сервер

статическая ip-адресация - мы вручную прописываем постоянный ip устройству, вместо того
чтобы его назначали динамически. это нужно для того, чтобы все знали точный адрес днс-сервера,
а роль днс сервера играет контроллер домена. так для всех остальных компьютеров в домене
днс-сервер это контроллер, а для самого контроллера - это он сам

днс-пересылка - это когда сервер не может сам ответить на запрос и пересылает его другому серверу

виды доверия:\
external - связывает два конкретных домена из разных лесов\
forest - связывает два леса

проверка подлинности в лесу - означает, что как только чел из другого леса прошёл
аутентификацию в моем лесу, то он попадает в "Authenticated Users", которым доступно всё в моем лесу
выборочная проверка - там разграничение идёт, что в каком лесу кому доступно

## последовательность моих действий
1. настроить статический ip на кд, в качестве днс-сервера указать себя \
-> через настройки\сеть\ethernet\свойства адаптера\ipv4
2. переименовать компьютер
3. через диспетчер серверов: управление -> добавить роли и компоненты \
-> выбрать роль "Доменные службы Active Directory"
4. после установки нажать повысить сервер до уровня контроллера домена, где \
выбрать "добавить новый лес" и ввести dns-имя домена, перезагруить

1. необходимо настроить dns-пересылку между доменами, для этого \
на виндовс\
в диспетчере серверов через вкладку DNS добавить сервер условной пересылки, \
выбрать опцию "Сохранять зону в ..."\
на альт-домен\
в /etc/samba/smb.conf в блоке \[global\] в строке с dns forwarder добавить ip
виндовского кд, перезапустить samba
2. как проверить что всё получилось: \
на виндовс\
nslookup pc-name.domain-name должен вернуть ip альтовского кд \
на альт-домен\
host -t A pc-name.domain-name должен вернуть ip виндовского кд

теперь можно добавлять доверие - через виндовский кд или samba-tool\
через виндовский кд:
1. через cmd открыть domain.msc
2. добавить доверие, выбрать доверие леса, и проверку подлинности в лесу
